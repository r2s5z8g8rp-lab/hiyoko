# 🎣 釣り日和（Hiyoko Fishing Planner）

釣りに行く日と釣り場を選ぶだけで、その日の **潮・月齢・日の出入り・天気・風・波・水温・おすすめ魚種・ポイントの狙い方** をまとめて調べられるWebアプリです。スマホのブラウザで使え、ホーム画面に追加すればアプリのように起動できます。

## できること

### 釣行プラン（その日をまとめて調べる）
- **釣り日和スコア**（0〜100）：潮回り・降水確率・風速・波高・雷から総合判定
- **潮回り**（大潮/中潮/小潮/長潮/若潮）と **月齢**・月相・旧暦日
- **満潮・干潮の時刻と潮位**、潮位グラフ（マズメ・夜間を色分け、タップで「上げ5分」などを表示）
- **日の出・日の入り**と朝マズメ/夕マズメ
- **時合い（狙い目の時間帯）**：潮がよく動く「上げ/下げ3〜7分」とマズメが重なる時間を★で強調
- **時間ごとの天気・気温・降水確率・風向風速・波高・潮の状態**（3時間ごと）
- **おすすめ魚種**：月・釣り場の種類・海面水温から上位6種と、釣り方・狙う時間・潮・コツ
- **ポイントの狙い方**：堤防/磯/サーフ/河口/船/川/渓流/湖 それぞれの攻め方
- **7日間比較**：前後の日の潮回り・天気・風・スコアを並べて、ベストな日を選べる
- 持ち物・安全チェック、強風・高波・雷の警告

### 釣り場（ポイント管理）
- 地図をタップして釣り場を登録（名前・種類・メモ）
- 地名検索・現在地からの登録
- 登録データは端末内（localStorage）に保存。JSONで書き出し/読み込み（機種変更・バックアップ用）

### 魚種図鑑
- 24魚種を月・釣り場の種類で絞り込み、シーズン中の魚を優先表示

## データについて
- 天気・風・波・海面水温・潮位：[Open-Meteo](https://open-meteo.com/)（APIキー不要・無料、CC BY 4.0）
  - 天気予報は **16日先まで**。それより先の日は、潮回り・月齢・日の出入り（端末で計算）と魚種のみ表示します。
  - 潮位は海洋モデルの予測値（平均海面基準）です。湾奥や港内では実際の潮見表とずれることがあります。
  - 潮位データが無い日は、**月の南中時刻＋高潮間隔**から潮時を概算します（釣り場ごとに「高潮間隔」を調整可能）。
- 地図：© OpenStreetMap contributors
- 魚種のシーズンは本州太平洋側の一般的な目安です。地域や年によって前後します。

> ⚠ 安全のため、出発前に気象庁の警報・注意報と現地の状況を必ず確認してください。

## 使い方（開発）

ビルド不要の静的サイトです（HTML/CSS/JavaScript）。

```bash
npm start      # http://localhost:8080 で起動
npm test       # 潮回り・月齢・日の出入りなどの計算テスト
```

## 公開（GitHub Pages）
`main` ブランチにマージすると `.github/workflows/pages.yml` が自動でデプロイします。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
公開後はスマホでURLを開き、「ホーム画面に追加」でアプリとして使えます。

## ファイル構成
```
index.html            画面
css/style.css         スタイル（ライト/ダーク対応）
js/app.js             画面の操作
js/planner.js         釣行レポートの組み立て・スコア・時合い
js/astro.js           月齢・潮回り・日の出入り・潮汐概算（オフライン計算）
js/weather.js         Open-Meteo 取得（天気・海況・地名検索）
js/fish.js            魚種データ・おすすめロジック・ポイントガイド
js/chart.js           潮位グラフ（SVG）
js/spots.js           釣り場の保存
sw.js, manifest       PWA（オフライン起動・ホーム画面追加）
```
